HALO Studio is a product engineering firm. One senior team designs, builds and runs **apps, websites, automations and dashboards**, with fixed scope, weekly demos and code you own.

| Engagement | What it is |
|---|---|
| **Sprint** | 2–3 weeks, fixed scope and price. A prototype, an audit or one automation. |
| **Build** | 6–12 weeks, fixed price. A full product: design, engineering, launch. |
| **Orbit** | Monthly retainer. Roadmap, iterations and care. |
